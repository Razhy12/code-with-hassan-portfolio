## 🚀 How to Use

### View Online:
Simply visit: **https://razhy12.github.io**

### Local Setup:
1. Clone the repository:
   ```bash
   git clone https://github.com/Razhy12/code-with-hassan-portfolio.git
   ```

2. Navigate to directory:
   ```bash
   cd code-with-hassan-portfolio
   ```

3. Open in browser:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx http-server
   ```

4. Visit: `http://localhost:8000`

## 🎨 Customization

### Change Colors:
Edit `style.css` and modify CSS variables:
```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    /* ... other colors ... */
}
```

### Update Content:
- Edit `index.html` to update text and links
- Replace email, phone, and social links
- Add your own projects and experiences

### Add New Projects:
Add new project cards in the Projects section:
```html
<div class="project-card">
    <!-- Your project details -->
</div>
```
